REL301m - Ôn trắc nghiệm (359 câu)

Cách đưa lên GitHub Pages:
1. Tạo repo mới trên GitHub (ví dụ rel301m-quiz), Public.
2. Upload cả 3 mục: index.html, data.js, .nojekyll (kéo thả vào trang "Add file > Upload files").
3. Vào Settings > Pages > Build and deployment: Source = "Deploy from a branch", Branch = main, thư mục "/ (root)", bấm Save.
4. Sau khoảng 1-2 phút trang chạy tại https://<tên-tài-khoản>.github.io/<tên-repo>/

Mở thử trên máy: bấm đúp index.html (cần internet để tải font và KaTeX hiển thị công thức).
